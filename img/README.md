# 图标资源清单

页面中的图标统一放在当前目录。文件名尽量保持稳定，后续替换图片时不需要改业务代码。

| 文件名 | 使用位置 | 说明 |
| --- | --- | --- |
| `nav-home.svg` | 手机底部导航：首页 | 当前已接入 |
| `nav-receive.svg` | 手机底部导航：收礼 | 当前已接入 |
| `nav-send.svg` | 手机底部导航：送礼 | 当前已接入 |
| `nav-friends.svg` | 手机底部导航：亲友 | 当前已接入 |

| `icon-delete.svg` | 收礼、送礼记录表的删除按钮 | 两处记录表共用 |

| 建议文件名 | 使用位置 | 当前占位内容 |
| --- | --- | --- |

## 不需要图片的元素

- 顶部品牌栏和底部导航属于移动端固定布局。
- 品牌标记、摘要卡片圆点、亲友头像首字母、状态圆点由 CSS 或文字生成。
- “收礼/送礼”类型标签是文字标签，不是图标。
